技术架构

🌐 前端架构

• 单文件 SPA，零框架依赖

• Lucide SVG 图标系统，风格统一

• 中英双语国际化，彩蛋式江湖模式

• 自研 2D Canvas 游戏引擎（6 个模块）

• 零外部依赖，纯原生 Web API

⚙️ 后端架构

• 腾讯云 CloudBase 云函数

• 火山方舟（豆包）LLM API

• CloudBase 内置数据库

• HTTP 访问服务统一路由

• 部署：CloudBase + Vercel 双平台

Vite Lucide CloudBase 豆包API Canvas Web Audio API MongoDB Atlas
