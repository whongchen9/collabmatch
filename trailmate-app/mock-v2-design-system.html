📱 Layout Architecture

Tab-Based Navigation

App
├── BottomTabBar (Home / Explore / Teams / Profile)
├── /home → HomeScreen
│   ├── HeroBanner (AI匹配入口)
│   ├── QuickActions (创建意图/快速匹配/加入队伍)
│   ├── ActiveIntents (当前意图卡片)
│   └── RecommendedRoutes (热门路线)
├── /explore → ExploreScreen
│   ├── SearchBar + Filters
│   ├── FeaturedRoute (精选大图)
│   └── RouteGrid (路线网格)
├── /teams → TeamsScreen
│   ├── MyTeams (我的队伍列表)
│   └── LobbyEntry (组队大厅入口)
├── /team/:id → TeamDetailScreen (Tab切换)
│   ├── TabBar: [聊天] [成员] [计划] [地图]
│   ├── ChatTab → 消息列表 + 输入框
│   ├── MembersTab → 成员网格 + 邀请
│   ├── PlanTab → AI计划 + 打卡点
│   └── MapTab → Leaflet地图 + GPS轨迹
├── /profile → ProfileScreen
│   ├── UserCard (头像/数据/称号)
│   ├── GamificationStats (段位/领域/图鉴)
│   ├── HikeHistory (徒步日志)
│   └── Settings Entry
└── /lobby → LobbyScreen (游戏风格组队大厅)
    ├── RoomGrid (房间卡片网格)
    ├── QuickMatch (快速匹配按钮)
    └── CreateRoom (创建房间)

State Management (Zustand Slices)

store/
├── authSlice.ts      → user, token, login/logout/register
├── intentSlice.ts    → intents[], matching state, createIntent
├── teamSlice.ts      → groups[], activeTeam, loadGroups
├── locationSlice.ts  → track[], checkpoints, GPS polling
├── matchSlice.ts     → matchedUsers/Teams, merge logic
├── gamificationSlice → rank, badges, titles
├── uiSlice.ts        → activeTab, panels, toasts, theme
└── index.ts          → combine slices into single store

Component Architecture (Atomic Design)

components/
├── ui/ (Atoms)
│   ├── Button.tsx        → btn variants
│   ├── Badge.tsx         → status/type badges
│   ├── Avatar.tsx        → user avatar with fallback
│   ├── Input.tsx         → text input variants
│   ├── Card.tsx          → card container
│   ├── Divider.tsx       → horizontal divider
│   └── Skeleton.tsx      → loading skeleton
├── shared/ (Molecules)
│   ├── UserRow.tsx       → avatar + name + meta
│   ├── RouteCard.tsx     → route summary card
│   ├── TeamCard.tsx      → team summary card
│   ├── IntentCard.tsx    → intent card
│   ├── CheckpointChip.tsx → checkpoint chip
│   ├── MapPreview.tsx    → static map preview
│   └── EmptyState.tsx    → empty state with CTA
├── features/ (Organisms)
│   ├── chat/
│   │   ├── ChatMessages.tsx
│   │   ├── ChatInput.tsx
│   │   └── SystemMessage.tsx
│   ├── match/
│   │   ├── MatchResults.tsx
│   │   └── MatchCard.tsx
│   ├── location/
│   │   ├── LiveMap.tsx
│   │   └── CheckpointTracker.tsx
│   └── lobby/
│       ├── RoomGrid.tsx
│       └── RoomCard.tsx
└── layout/ (Templates)
    ├── BottomTabBar.tsx
    ├── PageHeader.tsx
    ├── BottomSheet.tsx
    └── ScreenContainer.tsx
